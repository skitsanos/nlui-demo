# Research status and optional capabilities

This page describes current runtime boundaries, not an authorization to run billable experiments. Guarded SQL and controlled Ant Design rendering remain defaults. Recorded machine/reference successes do not establish general model reliability or human benefit.

## Visual explanations

`NLUI_INFOGRAPHICS=1` adds the read-only `get_infographic` tool and three starters. It is off by default. Comparison requires exactly two regions and an explicit observed EUR-revenue period; timelines show one order's recorded UTC events, not forecasts; the return process preserves full policy conditions and does not decide eligibility. The application owns all descriptors, fonts, templates, values and actions. Exact readable alternatives handle narrow space, unsupported surfaces and rendering errors.

Ordinary chat with an enabled experiment still calls the configured provider and can incur charges. For visual inspection without a provider or retained data:

```bash
NODE_ENV=production bun --no-env-file tests/fixtures/presentation-selection-server.ts
```

Open its printed loopback port. Stop it when finished. The lab uses authored reference selections and actual renderers, not live model predictions or participant measurements.

## Optional workflow Skills

`NLUI_SKILLS=1` enables the instruction-only prototype, off by default. Three embedded reviewed packs provide performance, order-investigation and return-policy guidance through a bounded `load_skill` function; no native provider attachment, shell, script or filesystem capability is enabled. See [Skills](/docs/skills) for the exact budgets, provenance, provider-free fixture and proposed eager/lazy comparison. No live quality or cost advantage is claimed.

## Provider-free evaluation

```bash
bun run eval:offline
bun run eval:fixtures
bun run eval:presentation
bun run eval:presentation:fallback
bun run measure:infographic
```

The 35 reference scenarios check bounded tool/rendering contracts. `presentation-v1` freezes 16 matched tasks, 39 wrong-infographic choices and 24 semantic canaries. `presentation-fallback-v2` separately aligns unavailable-format instructions and eligibility: use faithful chart/table/full-source fallbacks when a visual renderer is absent, messages for insufficient scope/evidence and informational results for verified missing records. All 35 eligible v2 reference choices pass on reused development fixtures; this is not held-out or live-model evidence. The build-footprint command measures an incremental bundle probe, not network transfer or human task time.
